موقع بطاقة تعريفية للاتحاد المصري للكيانات الشبابية
=====================================================

الملفات:
- index.html: الصفحة الأولى لإدخال اسم العضو واختيار صورته.
- card.html: الصفحة الثانية التي تعرض البطاقة.
- style.css: التنسيق المتجاوب.
- assets/: الشعارات المرفقة.

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في متصفح حديث مثل Chrome أو Edge.
3) أدخل اسم العضو واختر الصورة، ثم اضغط "إنشاء البطاقة".
4) في الصفحة الثانية استخدم "طباعة / حفظ PDF" لحفظ البطاقة أو طباعتها.

ملاحظات:
- البيانات تُمرر عبر sessionStorage داخل المتصفح، ولا تُرفع إلى خادم.
- إذا أردت نشره على الإنترنت، ارفع جميع الملفات مع مجلد assets إلى الاستضافة كما هي.
- هذا نموذج واجهة أمامية فقط؛ لا يوجد تسجيل دخول أو قاعدة بيانات لحفظ الأعضاء.
